# Vestlus B — Disain

Roll: loovjuht + UI-disainer + liikumisdisainer. Loe enne `docs/brief/00-lahteulesanne.md` (eriti §3 ja §5) ja `docs/tutkimus/2026-11-02-konversio-b2b.md`. Töötad Claude Designi lõuendil (artboardid), mitte koodis. Sisend sõnumite kohta tuleb vestlusest A (`docs/strateegia/`); kuni seda pole, kasuta kinnitatud tekste (00 §4).

## Ülesanne

1. Benchmark visuaalina: 6 konkurendi esilehe kuvatõmmised (desktop + telefon) ja 3 maailma parimat energia/B2B-lehte, igaühe kohta 3 rida: mis töötab, mis mitte, mida SAMA teeb paremini. Mõõdupuu: „parem kui keegi teine sellel turul".
2. Kolm paigutuskontseptsiooni esilehele, kõik täislaiuses sektsioonidega ja vahelduva rütmiga (mitte kahe veeru lava):
   - K1 „Kaart kui lava": võrgukaart on hero-klassi element, 3D-objektid tulevad sektsioonide taustaks.
   - K2 „Objekt": 3D-objekt heros täislaiuses taustana, tekst peal; kaart oma sektsioonis; 3D-kihid alamlehtedel.
   - K3 „Tõendid ees": hero + tõendiriba + kolm tellitavat ülal; 3D ja kaart „loe lähemalt" moodulitena.
   Iga kontseptsioon: desktop 1440 + telefon 390, hero ja 2 järgmist ekraani hi-fi, ülejäänud wireframe; põhjendus tõenditega (esimene ekraan, pikkus, liikumine, usaldus); mida 3D sellest sisuliselt selgitab (mitte kaunistus).
3. Disainisüsteem lõuendil: kuld logo põhjal, tüpograafia skaala Newsreader/IBM Plex Sans, nupud, kaardid, vormiväljad, allikajoonealused, 3D-ja kaardi raamid; liikumise reeglid (≤400 ms, ei kerimisjuhtimist, reduced-motion, mobiilis staatiline).
4. 3D-illustratsioonide juhend: isomeetriline realistlik stiil (6A), mõõtkava (akukapp ~2,4 m hoone kõrval), ei eraldi inverterikasti, inimesed objektil, elektrik kaameraga; iga stseeni roll ja tekst, mida ta kannab (ilma tekstita stseenil).
5. Kaardi moodul: kuidas kuus kihti jutustatakse (küsimus → kiht → arv → allikas), kodumaa esile, võrdlus nupuga; telefonis.

## Reeglid

- Logo faili ei muudeta. Ei eyebrow-silte, ei AI-stiili; oma nägu. Mitte must-kollane lamedus.
- Telefon esimesena: iga artboard ka 390 px; ei horisontaalset kerimist.
- Esimene ekraan: sõnum + tõend + CTA + telefon; järgmine sektsioon paistab.
